Arquivos atualizados e novos para a suíte Organização em Harmonia.

Inclui:
- Organização em Harmonia
- Atendimento em Harmonia
- Agenda Viva
- Base SQL compartilhada oh_*
- API de leads e lookup para BotConversa
- Integração BotConversa com campos oh_*
- E-mails para lead e alerta interno
- Documentação de atualização, Supabase, Vercel, GitHub e BotConversa

Rodar primeiro:
1. Substituir arquivos no projeto local.
2. npm run lint
3. npm run build
4. Rodar supabase/sql/20260627_14_organizacao_em_harmonia_base.sql no Supabase.
5. Configurar variáveis BOTCONVERSA_OH_* no .env.local e Vercel.
