# Arquitetura funcional — Organização em Harmonia

## Decisão principal

A Organização em Harmonia é a suíte principal. A Base Única é o núcleo interno compartilhado, e os módulos comerciais usam essa mesma base.

```txt
Organização em Harmonia
├─ Base Única
│  ├─ Organização
│  ├─ Pessoas
│  ├─ Funções
│  ├─ Permissões
│  ├─ Grupos
│  ├─ Módulos habilitados
│  └─ Auditoria
├─ Agenda Viva
├─ Atendimento em Harmonia
└─ Corrente em Dia
```

## Regra de fricção mínima

O primeiro formulário público deve pedir apenas:

```txt
Nome do contato
WhatsApp
E-mail
```

Não pedir no primeiro contato:

```txt
Solução de interesse
Nome da organização
Endereço
Funções
Permissões
Módulos
LGPD formal
Regras internas
```

Essas informações entram na área logada, quando a pessoa já iniciou o relacionamento com a AE.

## Cliente Fundador

A implantação assistida tem prazo sugerido de 30 dias a partir do Quero Conhecer para configurar a organização e treinar os envolvidos.

A avaliação de 30 dias como Cliente Fundador começa somente após:

```txt
Configuração mínima concluída
Treinamento inicial dos envolvidos concluído
Módulo prioritário pronto para uso real
```

Para o Tucxa, o primeiro módulo de validação recomendado é o Agenda Viva.

## Menus

Desktop logado:

```txt
Cabeçalho superior
Menu lateral à esquerda
Conteúdo à direita
```

Mobile logado:

```txt
Cabeçalho fixo
Pílulas de navegação no cabeçalho
Sem menu lateral à esquerda
```

## Diferencial comercial

Não vender como calendário, fila ou cobrança. Vender como uma forma de reduzir retrabalho, dar clareza para quem coordena, preservar a rotina humana da organização e manter memória operacional em uma base única.
