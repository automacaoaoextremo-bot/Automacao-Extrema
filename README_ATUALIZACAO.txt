Pacote de atualização — Organização em Harmonia

Inclui:
- Funil / CRM AE com Arquivar e Excluir lead.
- Base Única separada em páginas: visão geral, envolvidos, funções, entidades, grupos, vínculos em lote, localidades e orientações.
- Cadastro da Organização com aviso/atalho para múltiplas localidades.
- API da Base Única ampliada para localidades, entidades e vínculos em lote.
- SQL idempotente com oh_locations e oh_spiritual_entities.
- Documento de passo a passo da atualização.

Substitua os arquivos por cima do projeto local, rode o SQL, npm run lint e npm run build.
